# Карта Носкапа — Design

Интерактивная карта фэнтезийного мира Носкап для домашней НРИ-кампании (Daggerheart). Веб (desktop + mobile browser). Визуальное направление: **тёмное фэнтези / пергамент** — тёмный «чернильный» интерфейс, панели из состаренного пергамента, латунные акценты, гравюрные иконки. Карта всегда в центре, интерфейс её обрамляет, не перекрывая.

Пергамент — не плоская заливка: слой шума + мягкая виньетка через `background-image` (radial-gradient + SVG-noise), тонкая латунная рамка 1px.

## Typography

- **Display — Forum** (кириллица, self-hosted `/fonts/forum-*.woff2`): заголовки, названия локаций, шапка. Широкий трекинг, капитель-подобное настроение.
- **Body — Spectral 400/600** (кириллица, self-hosted): лор, описания, интерфейсные подписи. Line-height 1.65 для длинных текстов.
- Иерархия: h1 32–40px Forum, h2 22px Forum, метки интерфейса 12px Spectral 600 uppercase с трекингом 0.12em, тело 15px Spectral.

## Layout

- **Полноэкранная карта** (OpenLayers, тайлы `/tiles/{z}/{x}/{y}.jpg`) во всю область просмотра.
- **Левый сайдбар** (360px, пергамент, overlay поверх карты): шапка «Земли Носкапа», поиск, чипы-фильтры по типам, список локаций с иконкой, названием и коротким описанием. Сворачивается кнопкой.
- **Правая панель локации** (420px): арт, заголовок, тип и теги, длинный лор (markdown), блок заметок ГМ (только в режиме ГМ). На экранах < 900px превращается в bottom sheet на 75% высоты.
- **Нижняя панель инструментов** (по центру снизу): линейка, сброс вида, зум, индикатор режима ГМ.

## Pages & Screens

- **Web — Карта** (`packages/web/src/web/pages/index.tsx`) — единственный экран, композиция карты, сайдбара, панели локации и тулбара.

Компоненты (`src/web/components/`): `map-view.tsx`, `sidebar.tsx`, `location-panel.tsx`, `toolbar.tsx`, `ruler.tsx`, `ui/`.
Данные: `src/web/data/locations.ts` (типы локаций, координаты в пикселях исходной карты 4146×2354, origin — левый нижний угол, как в старом `locations.json`).

## Key User Flows

1. Игрок открывает карту → тайлы грузятся мгновенно → видит подписанные пины по типам.
2. Ищет локацию в сайдбаре или кликает пин → карта плавно центрируется → справа открывается карточка с артом и лором.
3. Меряет путь: включает линейку → кликает две (и больше) точки → видит лиги и дни пути пешком / верхом / форсированным маршем.
4. ГМ открывает `?gm=1` → появляются скрытые локации (помечены кровавой рамкой) и блоки «Заметки ГМ» в карточках.

## Motion

Один оркестрованный вход: сайдбар выезжает слева, тулбар всплывает снизу, пины проявляются каскадом. Панель локации — slide-in справа (fade + 12px). Всё через CSS-переходы, 180–260ms, ease-out.

## Architecture

Полностью статично: данные локаций — в TS-модуле, без базы. API-роут `ping` остаётся из шаблона. Состояние (выбранная локация, фильтры, режим ГМ, линейка) — локальный React-state в `pages/index.tsx`.
