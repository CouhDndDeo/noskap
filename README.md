# Карта Носкапа

Интерактивная карта мира для домашней НРИ-кампании: локации с лором, поиск,
фильтры по типам, линейка с расчётом дней пути и режим мастера со скрытыми
заметками.

**Карта:** https://CouhDndDeo.github.io/noskap/
**Режим мастера:** https://CouhDndDeo.github.io/noskap/?gm=1

---

## Как добавить или поправить локацию

Весь контент лежит в одном файле:

**[`packages/web/src/web/data/locations.ts`](packages/web/src/web/data/locations.ts)**

Правится прямо здесь, на GitHub, без установки чего-либо:

1. Открой файл по ссылке выше
2. Нажми карандаш (**Edit this file**) в правом верхнем углу
3. Поправь текст
4. Внизу — **Commit changes**

Через 2–3 минуты карта обновится сама. Прогресс сборки видно во вкладке
**Actions**.

Подробное описание всех полей, типов локаций и разметки лора —
в **[КАК-РЕДАКТИРОВАТЬ.md](КАК-РЕДАКТИРОВАТЬ.md)**.

### Где взять координаты новой локации

Открой карту с `?gm=1`, нажми внизу кнопку **«координаты»** и кликни по нужному
месту. Появится панель: вписываешь название, выбираешь тип, жмёшь
«скопировать блок» — и вставляешь готовый кусок в конец массива `locations`.

## Локальная разработка

Нужен [Bun](https://bun.sh).

```bash
bun install
bun run dev
```

Откроется на http://localhost:4200, страница обновляется при сохранении файла.

Проверить, что ничего не сломано:

```bash
bun run build:web
```

Самые частые ошибки при правке локаций — забытая запятая между блоками
и обратная кавычка `` ` `` внутри текста лора.

## Публикация

Происходит автоматически при пуше в `main` — GitHub сам собирает и выкладывает.

Собрать статику вручную (например, чтобы посмотреть локально):

```bash
./build-pages.sh
```

Результат — папка `pages-dist`.

## Режим мастера

Адрес с `?gm=1` показывает заметки `gmNotes` и локации с `hidden: true`.

⚠️ Репозиторий публичный, поэтому эти заметки может прочитать любой, кто
откроет исходный код страницы. Это защита от случайного клика, а не от
целенаправленного поиска.
